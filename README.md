# 🎁 Amigo Secreto – Sorteio Interativo com JavaScript

Este projeto é uma aplicação web simples e interativa que simula um sorteio de **Amigo Secreto**. Desenvolvido com foco em lógica de programação, manipulação do DOM e validações com JavaScript puro, é ideal para demonstrar domínio de fundamentos importantes do front-end moderno.

---

## 🚀 Funcionalidades

- ✅ Adição de participantes dinamicamente
- ✅ Validação de entrada (evita campos vazios)
- ✅ Lista interativa de participantes
- ✅ Sorteio aleatório com feedback visual
- ✅ Interface responsiva e acessível

---

## 🧠 Objetivos Técnicos

Este projeto foi desenvolvido com o objetivo de demonstrar:

- Manipulação de elementos HTML com `document.querySelector` e `getElementById`
- Uso de `Math.random()` e `Math.floor()` para lógicas de sorteio
- Limpeza e atualização dinâmica de listas com `innerHTML`
- Boas práticas com funções reutilizáveis e código limpo
- Separação de responsabilidades (HTML, CSS e JS)

---

## 🛠️ Tecnologias Utilizadas

- HTML5 semântico
- CSS3 com responsividade
- JavaScript puro (Vanilla JS)
- Google Fonts (Inter & Merriweather)

---

## 📦 Como Executar o Projeto

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/HenryCarvalho/challenge-amigo-secreto_pt-main.git
   cd challenge-amigo-secreto_pt-main
   ```

2. **Abra o arquivo `index.html` em qualquer navegador moderno.**

   > 💡 Não é necessário instalar dependências.

## 🧪 Testes Manuais Sugeridos

- Tente adicionar um nome vazio → alerta deve aparecer
- Adicione vários nomes → eles devem aparecer na lista
- Clique em "Sortear amigo" sem nomes → alerta de lista vazia
- Após adicionar nomes, clique em "Sortear amigo" → um nome aleatório será exibido
